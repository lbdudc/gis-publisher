    Usage: gispublisher shapefilesFolder

    General options:
      --help            # Print this info
      --generate, -g    # Just generate the product, do not deploy
      --version         # Print version
      --config          # Path to config file (default config file if not used)
      --only-import, -i # Only import shapefiles
      --bbox            # Bounding box to restrict the search. Format is expected to be:
                        # southwest_lng,southwest_lat,northeast_lng,northeast_lat
      --progress        # How progress is reported: "text" (default, readable lines)
                        # or "json" (one `@@gp {...}` line per event, for programs)
    To print debug messages, set the env variable DEBUG=true
